網頁製作選修。回到生活應用課後練習。

獨立課後練習 · 依完成條件前進

上完課，下一次從哪裡開始？

先找回自己的作品，再完成一個小修改。五關不必一天做完，也不按週數升級；達到該關的完成條件，再嘗試下一個概念。所有內容都可直接閱讀，勾選只是自己的紀錄。

這是網頁製作選修的延伸。手機與電腦兩條課程仍各 60 分鐘；手機課的 Gmail、Drive 示範各約五分鐘。這裡不需要付費方案、API key 或公開上線。

想先處理生活資料？可選信用卡、旅行規劃與股票／期貨資料分析，有連續兩堂各 60 分鐘教案與可下載虛構資料，再依需要回到網頁製作路徑。

今天只做一件事：如果檔案還找不到，先做第一關；若已有可用作品，直接核對前兩關，再做第三關。不需要先學會全部程式語法。

我的課後進度（選用）

只保存下方五個勾選，不保存 HTML、作品內容或自由輸入，也不會檢查作品是否正確。同一網站、同一瀏覽器的中英文頁共用紀錄；換裝置、清除網站資料或使用無痕模式可能失去紀錄。直接開啟本機檔案時，儲存行為依瀏覽器而異。

正在讀取本機勾選設定。

清除只影響這份課後紀錄，不會刪除你的 HTML 或主課程進度。取消啟用會移除已保存的課後紀錄。

第一關 · 看見檔案與畫面的關係

找回、保存並重新開啟 HTML

  1. 建立一個練習資料夾，例如「我的網頁練習」。開啟瀏覽器下載清單，找課堂下載的 .html，使用「顯示於資料夾」找到實際檔案，再複製到練習資料夾。
  2. 若程式還在課堂的「完整 HTML 程式碼」欄，先按「下載我的 HTML」。若只在 AI 回覆中，複製完整程式碼到純文字編輯器，另存為 index.html，使用 UTF-8；不要用 Word。Windows 另存時選「所有檔案」，並顯示副檔名，確認不是 index.html.txt。
  3. 用瀏覽器開啟這個檔案；確認位址對應練習資料夾。關掉分頁後，從資料夾再次開啟，確認作品還在。改程式用文字編輯器，看成果用瀏覽器。
  4. 如果當堂作品遺失，下載下方已準備的完成品，另存成 index.html 開始。它是教學範例，不是你已完成的作品。

完成條件：你能指出檔案在哪裡，並從資料夾重新開啟它。聊天中的程式碼與尚未下載的預覽，都不算已存好的作品。

第二關 · 把用途寫成可看見的需求

自己的主題，至少三個項目

選一個小用途，例如「閱讀準備清單」。先在紙上寫：誰使用、想完成什麼、至少三個項目。只用虛構或一般文字，例如「選一本書／準備筆記／記下問題」，不用姓名、地址、帳密或私人文件。

修改前先複製 index.html 為 index-before-topic.html。把以下需求中的例子換成自己的內容，再交給可用的程式 AI，指定只修改練習資料夾中的檔案：

請修改這個單檔 index.html。
主題：我的閱讀準備清單。
用途：閱讀前確認已準備好。
項目：選一本書、準備筆記、記下問題。
保留勾選、完成數量與全部重設功能。
不要加入外部套件、帳號、連線、追蹤或付費功能。
先說明將修改哪裡；修改後列出我可以親自執行的測試。
若在聊天中提供程式碼，請提供完整 HTML，不要只給片段。
沒有 AI，也能完成：只改可見文字
  1. 以純文字編輯器開啟剛下載的完成品，尋找 <h1>，只替換開始與結束標籤之間的標題。也可更新 <title> 之間的分頁名稱。
  2. 找到清單中每個 <span> 與 </span> 之間的文字，逐一換成自己的項目。保留既有四項也可以，至少三項即可。先不刪標籤、不改引號、不動程式區。
  3. 按儲存，在瀏覽器重新整理同一檔案。如果使用不同 HTML，先找相應的標題與清單文字；不確定時用提供的完成品練習。

完成條件：重新開啟後，看得到自己的主題與至少三個項目；能用一句話說明用途。再親自勾選兩項、取消一項、全部重設，確認仍為 2 → 1 → 0。

下一步：只增加一個小改動 →

第三關 · 一次改一件事

先寫預期，再要求修改

從一個小改動開始，例如「在標題下增加一行使用說明」。先備份為 index-before-help.html。你會先認識 HTML 負責內容，再認識 CSS 負責外觀；互動由 JavaScript 處理，這次不必一起修改。

請只在標題下增加這行說明：「完成後打勾，按全部重設重新開始。」
保留目前主題、所有項目、計數與重設功能。
不要增加其他功能或外部資源。
完成條件：重新開啟後能看見說明；原有 2 → 1 → 0 操作仍正確。
請列出修改範圍與測試步驟，不要把尚未執行的測試寫成通過。

沒有 AI 的做法：使用第二關的完成品，在 </h1> 後新增 <p>完成後打勾，按全部重設重新開始。</p>，儲存後重新整理。

如果出錯，先記下「做了什麼 → 實際看到什麼 → 希望看到什麼」。例如：「勾選兩項後仍顯示 0，預期應顯示 2；取消一項應為 1。」附上無私人資料的練習 HTML，請 AI 只修正這個問題，再跑第四關。不用把整個專題重做。

完成條件：能指出修改前後差別，且新說明確實出現在重新開啟的作品中。AI 說「已完成」不等於你已驗收。

第四關 · 回歸驗收與備份

改好以後，原本的功能還在嗎？

  1. 重新開啟：儲存並關閉作品分頁，再從資料夾開啟目前 index.html。確認自己的主題、至少三項內容及新增說明都在。
  2. 2 → 1 → 0：先按全部重設；勾兩個不同項目，完成數為 2；取消其中一項，為 1；按全部重設，為 0，所有勾選都取消。重複一次，確認不會累加錯誤。
  3. 窄畫面與鍵盤：把瀏覽器縮窄到約 390px，或用瀏覽器開發工具的裝置模式。長文字可換行、沒有整頁左右捲動，按鈕不被遮住。用 Tab 移到勾選框，按空白鍵切換；移到重設按鈕後按 Enter，確認焦點看得見且功能正確。瀏覽器模擬不是手機實機測試。
  4. 做一份可辨識備份：驗收通過後，複製為 index-good-YYYYMMDD-v1.html（換成實際日期）。下一次修改只動 index.html，保留這份可用版本。
  5. 練習復原：先開啟備份，確認它真的可用。若目前版本壞了，先另存為 index-broken.html 留下問題，再將可用備份複製回 index.html；重新開啟並重跑前三項。不必刪除整個資料夾。

下載空白學習紀錄，記下檔名、修改、預期／實際結果及備份位置。它是可自行填寫的文字範本，不會自動讀取或備份作品；請用文字編輯器填寫後儲存。

三種「保存」不是同一件事

  • 儲存 HTML：保存程式碼與預設內容。下次能開啟作品，不代表記得上次勾了什麼。
  • 保存使用進度：額外寫程式，把勾選記在特定瀏覽器。原始完成品沒有這項功能；本課後頁的勾選記錄也不會替你的作品加入功能。
  • 公開上線：另外把檔案放到網站服務，讓別人透過網址存取。下載檔案、雲端備份或本機預覽都不等於完成公開發布。這份延伸練習不要求發布。

完成條件：上述測試有實際結果，能開啟可用備份；有失敗就先修復或還原，不把勾選當通過證據。

下一步：只選一個專題或進階功能 →

第五關 · 前四關可重做後再選修

讓同一個小作品更有用

選一題，先寫三項完成條件，再做一個版本。內容全部用虛構資料；一次只增加一個概念。若還不能自己重新開啟與還原檔案，先重做第四關。

專題 A：活動準備清單（HTML 內容與 CSS 排版）

例：虛構的閱讀聚會。至少三項準備工作，加上「活動前／當天」分組。完成條件：分組標題清楚；所有項目計數仍正確；390px 長文字與按鈕可讀。先只加分組，不同時加入日期提醒或通知。

請把我的清單分成「活動前」與「當天」兩組，使用虛構活動資料。
保留目前計數與全部重設；兩組都要計入總數。
不要加入登入、日曆連線或通知。提供可重新開啟的單檔 HTML。
測試跨組勾兩項、取消一項、重設，以及窄畫面。
專題 B：三題知識小測驗（JavaScript 條件判斷）

題目自訂為生活常識或本課知識。例如「HTML 存檔是否等於公開上線？」答案為否。完成條件：三題各有可查證答案與說明；全部答對得 3／3，故意錯一題得 2／3；未作答會提示，不算已完成；重設後清空作答。先把答案寫在紙上，再請 AI 實作並核對。

做一個單檔 HTML 三題測驗，題目、正確答案與解釋使用我提供的內容。
送出時若有未作答題目，提示補答；全部作答後顯示分數與解釋。
重設會清空答案與結果。不要連線或記錄個資。
請列出全對、錯一題、未作答、重設與鍵盤測試。
專題 C：虛構閱讀清單（陣列資料與畫面）

先用三本虛構書名與「想讀／已讀」狀態。完成條件：顯示三筆；切換已讀只顯示對應項目且數量正確；沒有符合項目時顯示「目前沒有項目」，切回全部能找回資料。先不做登入、資料庫或線上同步。

請用三本虛構書名製作閱讀清單，資料集中放在一個 JavaScript 陣列。
提供「全部／已讀」篩選，顯示符合數量；空結果時要有明確文字。
保留全部原始資料，篩選不能刪除資料。不需要外部套件或帳號。
列出全部、部分符合、零筆符合與切回全部的測試。
進階挑戰：讓自己的清單記住勾選（瀏覽器儲存）

開始條件：第四關已實測通過，且手邊有可用備份。這是待製作的功能規格，不是原始範例已具備的能力。先理解「重新開啟檔案」和「記住使用狀態」的差別。

請為我的單檔清單加入可選的「記住勾選」，預設關閉。
使用 localStorage，只保存項目的固定 ID 與勾選狀態，不存個資。
標題或項目順序改變時，不可把勾選錯配到別的項目；新項目預設未勾選。
啟用後在同一瀏覽器、同一位址重新載入，能還原勾選並重新計數。
「全部重設」也清除保存的勾選；取消記住要移除這個作品的紀錄。
不得清除其他網站或練習的資料。儲存被阻擋或內容損壞時，
仍可勾選、取消與計數，並顯示目前無法保存，不能假稱保存成功。
不新增雲端、登入或公開發布。保留原本的主題與至少三項內容。

自己驗收：未啟用時先勾兩項，重新載入確認不靠此功能保存；啟用後勾兩項，重新載入應仍為 2；取消一項並重載為 1；重設並重載為 0。更換項目順序不錯配；取消記住後重載不保留。另請協助者測試儲存被阻擋與損壞時能繼續操作；沒測到的項目寫「未驗證」。

瀏覽器可能自行恢復表單狀態，不能只憑一次重載就判定儲存功能正確。file: 本機檔案的儲存支援與資料範圍依瀏覽器不同；課堂隔離預覽也不適合測試儲存。若結果不穩定，請講師協助使用固定的本機預覽位址後重測，先保留不保存進度的版本。

復原：加入功能前先備份。失敗時保留失敗版，再還原可用 HTML。瀏覽器紀錄與 HTML 是分開的；先用作品專用的清除功能移除其紀錄，或請協助者只移除該作品的儲存鍵，不用清空所有網站資料。使用者進度不會因備份 HTML 而自動備份。

沒有 AI 的備案：先選專題 A，在備份副本中只改主題與項目文字，再畫出分組草圖，寫下驗收步驟。新增互動做不出來時，保留可用版本與問題紀錄，向講師求助；不把草圖記為已完成程式。

做到這裡，再考慮學檔案拆分、版本控制或公開發布。工程入門指南 ↗ 是額外參考；先從自己目前需要的一章開始。

卡住時，先查這幾件事

打開檔案看到程式碼，或找不到下載檔

檢查真正副檔名是否為 .html；用「開啟方式」選瀏覽器。檔案找不到時，回瀏覽器下載清單找實際位置。只有聊天程式碼或預覽時，回第一關重新儲存。

儲存了，畫面卻沒變

確認編輯器已儲存；比對瀏覽器位址和正在修改的資料夾／檔名，避免看著備份。重新整理；仍不同時關閉分頁，再從剛修改的檔案開啟。不要同時改多個副本。

按鈕壞了，AI 又加了一堆功能

先另存失敗版並還原備份。用「操作、實際結果、預期結果」回報一個問題，要求只修這一點，保留主題與清單。修好後重跑第四關，不只測新增功能。

我只有手機，或暫時不能使用 AI

先用手機課的虛構通知練習：挑兩則通知，寫一個簡短要求，再補一個自己的條件；對照原文核對期限、來源及未知資訊，另向原發布者確認可信度。沒有 AI 就修改課堂的預備草稿；把結果存到備忘錄並重新開啟。這是獨立有效的延伸；要做檔案修改時再使用電腦，不必購買工具。

下載 HTML 給朋友，對方會看見我的勾選嗎？

一般只會拿到程式碼與預設內容。瀏覽器中的勾選紀錄不會自動包進 HTML，也不會跨裝置同步。先用虛構內容，說清楚哪些功能已測、哪些未測，再決定是否分享。
