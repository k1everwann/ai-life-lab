Shared opening · Project examples

Start with something you want to do

During the lesson, spend about 90 seconds each on investment research and the study website. Browse the other examples yourself. Find one small task you would like to complete.

Public demonstration boundaries: These interactive examples are reconstructed with fictional data. They are not screenshots of private pages and do not embed or connect to private systems.

Shared foundations

Three basic ideas about AI

01

Models generate content

A model learns patterns from many examples and generates text or code from the material in front of it. A fluent answer can still contain invented details.

02

Tools get data or take actions

You can paste text, provide files, or authorize a connector to find information. What it can read and do depends on its tools and permissions.

03

You decide whether the result is usable

Read the original, check dates, calculate totals, and try the buttons. A generated list does not complete a registration. Generated code does not prove a feature works.

One piece of context can change the answer.

“For tomorrow's activity, I should bring ___.” Choose a context and see a possible continuation.

A picnic mat, water, and trash bags

Context helps produce suitable suggestions. Check the activity notice for the actual rules.

2

Start with one sentence, then clarify what you need.

You do not need a long prompt at the start. Get a draft and see what needs more explanation.

① Ask for one thing

Please organize notices A–D into a task list.

Use this with the four copied notices. Actual AI replies may vary.

② See what is missing

Are deadlines separate from activity dates? Was the correction used? Were unspecified opening hours invented as facts?

The checking questions below use a prepared draft with deliberate problems, not your current AI reply.

③ Add one requirement yourself

After one revision, view the combined task

Use only notices A–D to draft tasks. Include what to do, the action deadline, activity time, source, and information to confirm. Corrections take priority over old notices. Separate activity dates from registration deadlines. Mark unspecified times or statuses as “to confirm”; do not invent them. Organize only: do not register, send replies, or pay.

Cannot use AI yet?

Use the prepared draft below to judge and revise. In an adult-operated group, the child supplies the request and identifies sources while the adult sends it. Record platform operation separately when the learner did not do it personally.

Check both faithful summaries and trustworthy originals.

First ask whether AI faithfully summarized the source. Then ask where the original information came from. Claims in forwarded messages, screenshots, and emails may still need confirmation from the publisher.

  • Rescheduled activity: return to the organizer's official notice and check the publication date and updated version.
  • An unknown message asks for payment or login: confirm using an official website or contact method you already know, rather than relying only on its links.
  • Stock information: check official company or exchange announcements, data timestamps, and units. Neither an AI summary nor a group rumor is announcement evidence.

Quick practice: AI correctly copied a forwarded message saying “the activity moved to the afternoon.” What is still missing?

See how to judge it

The organizer's official update is still missing. You can say what the forwarded text claims, but cannot use it alone to confirm that the activity really changed.

Instructor demonstration · About five minutes each for Gmail / Drive

The same method works with email and cloud-drive material.

Check the connected account, allowed actions, and search scope first. Search results are not guaranteed complete. Finding a filename does not prove the file contents were read. Open and check the source.

Mobile availability depends on account plan, region, plugins, and permissions. If connectors are unavailable, paste text or provide an accessible file to complete the same exercise.

Gmail: find recent matters that may need action

From the emails accessible in this search for the last seven days, list matters needing my reply or action. Include original email sources, deadlines, and search scope. Read does not mean completed. Mark unclear deadlines “to confirm.” Read and organize only.

Google Drive: compare family travel plans

Read only the plan documents I specify. First confirm dates, headcount, currency, and per-person or whole-group pricing. Compare totals and included items, cite document sources, and mark gaps without guessing.

Route B · 60 minutes

Computer: build a personal checklist webpage

Use a prepared Codex, Claude Code, or another AI that generates code. VS Code is an editor; confirm that an AI tool is also available in your setup. Complete installation and login before class.

Try the finished example first ↗

Your first webpage: four places and six steps

Build request: the words explaining what you want. AI conversation or coding tool: where you send that request. HTML file: a saved file containing the code, such as index.html. Browser: where you open and operate that file. The Build request box below contains instructions for AI; the preview box later needs complete HTML code.

  1. Create a new practice folder.
  2. Fill in your title, purpose, and at least three items below. Choose “Create my Build request,” then “Copy Build request.”
  3. Paste the Build request into your available AI tool and send it.
  4. If the tool creates files, find its index.html in the practice folder. If it returns text, copy the complete HTML, from the document start to the final closing tag. Exclude surrounding explanation and Markdown fences such as ```html and ```.
  5. Save the file as UTF-8 plain text named index.html, rather than index.html.txt. In Windows Notepad, use Save As and choose “All files” for the file type; show filename extensions to check the result. In macOS TextEdit, choose “Make Plain Text” before saving. If a coding tool already created the HTML file, check its name and location.
  6. Open index.html in a browser. Check two items, uncheck one, then reset everything: the count should be 2 → 1 → 0. You can also paste the complete code into this lesson's preview later.

File saved: your HTML file exists and can be reopened. Keep checked progress: the webpage remembers checked items after reopening; our first example does not. Public website: other people can visit a published URL. Saving or previewing the file does not publish it.

2

Learning to request a revision is a skill too.

Say what you did, what you saw, and what you expected. Then ask AI to fix it.

A revision based on an observed problem

Use this only if the issue actually occurs: After I check two items, the display still says 0 completed. Please fix the count update and list tests for checking, unchecking, and resetting everything. Keep my title and checklist text.

If the count already works, make a real change instead: add “Bring a small towel” to my checklist, keep existing items and interactions, then tell me how to check the new total and reset.

Takeaway card

Where do I find it after copying or downloading?
  • Copy: open your phone's notes app, create a note, press and hold to paste, and confirm it has saved.
  • Download: look in your browser's downloads or your phone's Files downloads folder. Open ai-life-takeaway.txt. The location depends on phone and browser settings.
  • Before leaving, reopen the note or downloaded file to confirm your result is really there. If you cannot find a download, use copying instead.

Results, follow-up requests, and free text are not uploaded or saved automatically. Copy or download them before closing. Checkbox and checking-question progress stay only in this browser.

Remember these four questions.

  1. What do I want to complete?
  2. Which material should it use?
  3. If information is missing, will it say so?
  4. What will I check myself?
