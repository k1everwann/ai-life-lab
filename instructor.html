備課 01

一堂課的目標與提案

這份教材供一般家庭與 AI 零基礎學員使用。依現場設備選擇手機或電腦路線，每一套各自完整 60 分鐘，包含相同的前 7 分鐘成果展示與原理說明。

讓學員完成一件自己用得上的小事，並親自確認它是否可靠、是否能用。

對總經理的三十秒說明

我們用真實生活專案讓學員看見可能性，再用手機整理通知，或用電腦做出自己的小網頁。課程交付的是可核對的待辦草稿或可操作的作品；教學網站可分享、課後可重做。

路線設備與前置可帶走的成果
A 手機生活應用手機與可用的文字 AI；核心練習不需連接器經本人核對的待辦草稿與下次可用的需求
B 電腦製作網頁電腦與已能使用的 Codex、Claude Code 或程式 AI自己的 HTML、一次修改與實測紀錄

上課與分享入口

https://k1everwann.github.io/ai-life-lab/

先開主頁，展示成果，再選 A 或 B。講師頁有流程、備案與下載。兩條路線是不同場次的備案，不要求一位講師同時教完兩套。

備課先看三件事

• 確認學員設備與工具已可用，安裝登入在課前完成。

• 講師只用教學帳號與虛構資料示範連接器，不投影私人信箱。

• 找不同熟練度的人先試走，記錄卡住的位置與時間；尚未宣稱教學成效已驗證。

備課 02

共同開場與成果展示講稿

0-3 分鐘只主講投資研究與學習網站，各約 90 秒；3-7 分鐘解釋原理。每例說明：自己的問題、可操作成果、AI 與工具分工、學員今天能開始的一步。

主講兩例，其餘供自行點閱

專案可以這樣說從小處開始
TickForge Community（主講）公開交易研究框架：資料、規則、選用 AI 複核與風險檢查分工，只做模擬；不展示私人投資狀況。股票資料的來源、時間、單位與缺漏核對清單
Forge Outfit天氣資料、選衣規則、AI 示意圖與排程提醒各有分工。下雨天出門準備清單
Forge Japanese N1（主講）用網站整理教材與練習，作答後看證據；不是即時 AI 家教。三題自己的練習與解析
Forge Glow用資料庫與 API 整理書籍、電影與影集收藏；不把一般資料庫叫做 AI。三本書的閱讀清單
公開工程教材把實作整理成下一個人能學的網站與原始碼。今天之後還能繼續深入。保存需求、修改與驗收過程

三個共同原理

• 模型從範例學到模式，依眼前指令與材料生成答案或程式；流暢不保證正確。

• 連接器與工具決定能取得什麼資料、能執行什麼動作；沒有授權的資料不能假設已讀到。

• 人要回原文、算總額、實際操作。把待辦列出來，不等於已完成；產出程式，也不等於功能正確。

投資研究示意中，AI 逾時時拒絕候選進場，風險退出不等待 AI；先前狀態不明則阻擋新進場。不展示價格、績效或買賣建議，今天從核對清單或小測驗開始。

展示區為經標示的虛構資料重現，並非正式系統截圖。不要臨場打開私人主機總覽、衣櫃、真實郵件或部署設定。

備課 03

A 手機路線 六十分鐘教案

時間活動看得見的成果
0-7 分成果展示與共同原理看見用途，知道結果需要核對
7-15 分讀通知，找出錯誤草稿區分活動日、截止日與未知資訊
15-23 分短問句、看缺漏、補一個要求知道指令可以依草稿逐步補充
23-38 分手機五步操作與一次修改複製、貼上、返回核對並保留成果
38-48 分Gmail 與 Drive 各約五分鐘看懂工具取資料與核對的分工
48-55 分查核原文、發布者與預算區分忠實整理、來源可信與未知費用
55-60 分保存成果與出口題重新找到自己的清單，說出查核方式

四項學員驗收

• 先用簡短任務取得草稿，再親自補一個要求；成人操作組由孩子說需求、成人送出，分開記錄平台操作。

• 回通知原文，區分一項報名截止與活動日期，修正錯誤或遺漏。

• 辨識至少一項目前無法判斷的內容，不接受 AI 自行補出的時間。

• 能說明原文也需要核對發布者；保存修正清單後重新找回。搜尋不保證完整，清單不代表已執行。

跟不上時怎麼調整

五步操作：按複製 → 切到 AI 長按輸入欄貼上並送出 → 切回教材 → 對照通知、補要求修改 → 把成果貼到帶走卡。成人操作組與無帳號組保留判斷練習，不混算本人平台操作。

Gmail、Drive 各五分鐘維持正式課程。先試走登入與切換；練習用同一組通知，不另加情境。結束時可複製到備忘錄或下載，再開啟確認真的保存。

備課 04

A 練習資料與查核答案

全部為虛構教學資料，情境日 2026-11-02，日期與時間採 Asia/Taipei。

通知內容
A / 11/02 社區自然觀察活動11/08（日）09:00-12:00 舉辦；11/05（四）18:00 報名截止。透過社區表單報名，成功與否需等確認信。
B / 11/01 手作課舊通知原訂 11/07（六）10:00，在一樓教室。
C / 11/02 手作課更正通知更新 B 為 11/07（六）14:00、二樓教室。11/04（三）20:00 前回覆能否出席。
D / 11/02 訂單取貨提醒11/06（五）前到指定門市領取，沒有提供營業時間或最後取貨時刻。

先短問，再補條件

先問：請把通知 A-D 整理成待辦清單。回原文看看期限、版本與未知時間有沒有問題，再親改一個要求，例如：請附通知來源，沒寫明的時間標待確認。

修改後可參考的整合版需求

請只根據通知 A-D 整理待辦草稿，列出要做什麼、處理期限、活動時間、來源與待確認資訊。更正通知優先於舊通知，區分活動日與報名截止日。未寫明的時間或狀態標示待確認，不自行補齊。僅整理，不代為報名、回信或付款。

參考答案與易錯點

• 活動報名：11/05 18:00 截止，活動為 11/08 09:00-12:00，來源 A；報名是否成功仍需確認信。

• 手作課回覆：11/04 20:00 截止；課程為 11/07 14:00、二樓，來源 C 更新 B。

• 包裹：11/06 前領取，來源 D；營業時間、最後取貨時刻均未知。

查核題依序為：與原文矛盾、有依據、目前無法判斷。對得上原文只代表忠實整理；若原文是群組轉傳，仍要向主辦單位確認日期與更新，不能把轉傳當作正式通知。

備課 05

A 連接器與雲端資料示範

Gmail 約五分鐘

使用事先準備的教學信件。先確認登入帳號與允許動作，再指定時間範圍，展示一筆待辦如何點回原信核對。

請查找最近七天本次可取得的信件，整理需要我回覆或處理的事項，附原信來源、期限與搜尋範圍。已讀不代表完成；沒有明確期限標待確認。僅讀取與整理。

不宣稱信箱已完整掃描，也不要求全班現場授權私人帳號。連接器出錯時，直接使用相同的虛構通知包示範，不花十分鐘排查授權。

Google Drive 約五分鐘

事先在教學 Drive 放入預算資料，以文件連結指定讀取。若只能找到檔名，不能假設已讀到內容。先確認日期、人數、幣別與計價單位，再分析。

方案已知資料可驗證的計算
A同日四位成人，每人 800 元，整團交通 1,200 元，午餐未知800 × 4 + 1,200 = 4,400 元；午餐另計
B同日四位成人，整團 4,000 元，交通與午餐已含已知總額 4,000 元

CSV 與資料說明可由講師頁下載。A 的午餐未知，不是零元；B 的交通已包含，不再重複加一次。此為算術與資料口徑練習，不是實際旅遊報價。

課前必查

• 用實際 iPhone／Android、預計帳號與網路試走。可用功能受方案、地區、插件與權限影響。

• 12 歲的 ChatGPT 實際互動由成人進行，孩子提出要求與查核；入口前說明，沒有成人時用本頁草稿。不要求借帳號。

• 只讀取指定教學資料。寄信、報名、付款與建立日曆不列入本堂練習。

備課 06

B 電腦路線 六十分鐘教案

時間活動看得見的成果
0-7 分成果展示與共同原理看懂從小問題到作品的過程
7-15 分看成品，寫三項需求選一個用途與最小功能
15-23 分生成、存檔與預覽示範分辨程式碼、檔案與可操作畫面
23-38 分製作第一版自己的 HTML 可以重新開啟
38-48 分測試後修改一次依實際結果描述問題
48-55 分窄螢幕與互動互測勾選、取消、重設與數量一致
55-60 分保存作品與說明限制知道是否保存進度，選一個後續方向

課前前置

• 確認 Codex、Claude Code 或其他工具已可登入、接收需求及取得程式碼。VS Code 是編輯器，另確認是否有 AI 能力。

• 準備新的練習資料夾與瀏覽器。當堂不集中安裝工具、處理 API 金鑰或設定雲端環境。

• Codex 本機模式與雲端模式能存取的檔案不同；依實際工具確認作品要存到哪裡。

最小作品

一個 index.html，含標題、用途與至少三個項目。支援勾選、取消、即時計數與全部重設，窄螢幕可閱讀。第一版不要求保存進度，但須明確說明。

完成品：examples/my-checklist.html；起步範本：examples/starter.html。範本刻意只有內容，讓學員請 AI 補上互動。

備課 07

B 製作需求 測試與故障備案

請在新的練習資料夾製作單檔 index.html，主題是我的旅行準備清單，包含用途說明與至少三個項目。可勾選與取消，完成數即時更新，提供全部重設按鈕。使用繁體中文，390px 手機寬度也可操作。HTML、CSS、JavaScript 放同一檔，不使用外部套件、API、登入或網路字型。第一版重新整理後可重設，請在畫面說明。只處理練習資料夾，不部署。完成後列出我應親自執行的測試步驟。

四項可觀察驗收

測試實際操作成功條件
重新開啟關閉後再開自己的 HTML看見自訂標題與至少三個項目
勾選與取消勾兩項，再取消一項完成數依序 2、1
全部重設至少勾一項，再按全部重設所有勾選清除，完成數為 0
窄螢幕與修改縮窄視窗，完成一項自訂修改再測內容可讀，按鈕可用，受影響功能正確

描述錯誤的句型

我做了什麼 → 看到什麼 → 期待什麼。例如：勾選兩項後仍顯示 0，預期應為 2；請修正計數並保留我的標題與清單。

故障備案

• 檔案不能開：先確認檔名為 index.html，而非 index.html.txt；使用純文字存檔。

• 工具不能直接改檔：改請它輸出完整 HTML，複製到編輯器後存檔。

• AI 不能用：用起步範本與完成品比較，先做需求與測試；註明尚未完成 AI 製作步驟。

• 預覽與獨立檔案不同：隔離框架會限制部分功能。程式只用可信任的練習碼，下載後再測儲存等能力。

公開分享放在課後擴充。先移除私人內容，再選擇發布方式；生成、存檔、預覽與公開上線是不同階段。

備課 08

現場準備與資料來源

開課前與現場檢查

• 課前在桌面、手機與投影上試走主要流程。確認公開網址、PDF、範例與複製按鈕可使用。

• 共用七分鐘後選一條主課程；設備混合時，另一條提供自學指引或助教協助，不讓一位講師同時講兩套。

• 依操作熟練度提供提示，避免以年齡判斷能力。讓操作員與查核員輪換；需要時使用瀏覽器縮放。

• 網站不會自動保存自由輸入與 HTML。帶走卡含今天成果：可複製到備忘錄或下載 ai-life-takeaway.txt；請學員重新開啟確認。

素材採用與界線

展示均為虛構重現，無私人截圖或嵌入。股票研究依公開社群版說明，不代表私人正式系統；N1 與收藏數量不作成效證明。

課後練習與新手帶領

先在電腦路線的「第一次做網頁」確認教材、AI 工具、HTML 檔案與瀏覽器的位置。讓學員指出自己的檔案，再測試勾選 2→取消 1→重設 0。

「保存檔案」不等於「保存勾選進度」，本課第一版不保留勾選。用實際觀察提出修改；沒有出錯時，新增一項需求，不把範例錯誤說成實際結果。

課後練習提供分關步驟、可複製需求、完成條件與復原方式，另有英文版。記錄看懂、備案練習與親自完成的差異，課後活動不占兩條各60分鐘的課時。

PDF 為繁體中文版；新增的新手引導、雙語與課後路徑以網站為準。英文完整教案可用上方 English 開啟。
