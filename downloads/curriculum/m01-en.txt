Your first request

Using only notice A1, write one action with its deadline and source. List one item that needs confirmation. Do not guess.

1. Keep this lesson tab open. Open another browser tab and visit an AI tool you can use. Sign in using its interface. If access is unavailable, observe a demonstration and record hands-on work as pending.
2. Start a new chat in the AI tool and find its message input. Return to this lesson, copy the source, switch back to the AI tool, paste it, then paste the prompt.
3. Check that the text is complete, then use the tool's send control. Wait for its answer. This happens in the AI tool; copying text in this lesson does not submit it.
4. Return to the lesson and compare: the reply deadline is 11/18 18:00, not the activity date 11/21. The location remains unknown. If needed, ask: 'Correct this using A1; do not guess the location.'
5. Return to this lesson. Paste your submitted request into the request field and the answer, source A1, and verification into the result and verification field. Select Download this lesson record, then open the downloaded text file from the browser download list and check its contents. You may also save a copy in your practice folder.
