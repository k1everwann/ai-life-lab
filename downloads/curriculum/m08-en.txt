Your first request

Generate a complete standalone HTML file from the source, including CSS and JavaScript. No external libraries, network, or tracking. Preserve the three tasks and order. Each task needs a checkbox with a clickable label. Display n/3 completed. A reset button clears all checks and returns the count to zero. Support narrow screens, keyboard focus, and keyboard checking. Clearly state 'Progress is not saved; reopening resets it.' Clear checked states on initialization; do not use localStorage. Return complete HTML and a short saving instruction.

1. Create a local ai-practice folder. Submit the source and prompt to a code-capable AI tool and save your request.
2. Obtain complete code from <!doctype html> through </html>. If it contains omissions or 'same as above,' ask for the entire standalone file.
3. Paste it into a plain-text editor without Markdown triple backticks. Save as checklist.html in UTF-8. In Windows Notepad select all files and check that it is not checklist.html.txt.
4. Open the file in a browser. Check the first two items: 2/3. Uncheck the first: 1/3. Reset: 0/3. Verify all original labels, narrow the window, and use Tab and Space to operate it.
5. Close the file tab and reopen it: expect 0/3. If it fails, report steps, expected result, and actual result to AI; save a corrected version and retest.
6. Make your own change from 'Bring a water bottle' to 'Bring a notebook.' Ask AI to change only that item. Save checklist-v2.html and verify the labels and 2→1→0 again.
