Practice material

Fictional checklist: title 'Before departure'; tasks in order: 'Download tickets', 'Confirm meeting location', 'Bring a water bottle'. No network or progress saving; reopening starts at 0/3.

Request for AI

Make a complete HTML checklist for these three tasks, with CSS and JavaScript in the same file and no external libraries or network. Each task can be checked. Show n/3 completed and a reset button. Support phones and keyboards. Do not save progress: reopening clears it to 0/3, and the page must say so. Give me the complete code without omissions.

1. Paste the Practice material and Request for AI into your AI tool to get complete HTML code.
2. Copy the code into this page’s Complete HTML code field without the surrounding triple backticks. Select Update isolated preview.
3. In the preview, check two items, uncheck one, then reset. Counts should be 2/3, 1/3, and 0/3.
4. Select Download this HTML. Open the file from your browser downloads and check that reopening starts at 0/3.
5. In the same AI chat send: “Change only Bring a water bottle to Bring a notebook; give me complete updated HTML.” Paste the new code into the workspace, update the preview, and try again.
