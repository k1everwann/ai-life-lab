Practice material

Model-room fan scenario. Fictional temperature readings for text simulation; no equipment connection.
Rule: at 28°C or above, create one simulated model-room fan start request and one notification. Below 28°C, do nothing. With no temperature, do nothing for now. If an event ID has already been processed, do not process it again.
In order: E01: 27°C; E02: 28°C; E03: 29°C; E04: no temperature; E02: 28°C (the same event sent again).

Request for AI

Try the rules below. For each row show temperature, whether it produces a simulated start request, whether it notifies, and one reason. Do not process a repeated event twice. Use text simulation only.

1. Paste the rules, five readings, and request into AI to get a trial table.
2. Check that 28 and 29 degrees each produce one request and notification; the missing reading produces no action.
3. Then send: “Change the rule to above 28 degrees and rerun these five events from an empty record.” See whether the 28-degree event stops triggering.
4. Compare the two versions: 2 requests first, then 1. This tests a rule; it does not connect to real equipment.
