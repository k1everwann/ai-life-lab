# AI Life Lab

Public Traditional Chinese and English teaching materials for everyday AI, with flexible modules for different prior experience.

- Current audience: ages 12–18 in one mixed-age class. Use shared creative/student-life tasks with freely chosen challenges, never age-based ability labels. Each lesson needs an account-independent prepared-material path, a learner-chosen change, a verifiable check and a saved result. Adults operate ChatGPT for under-13 learners; eligible minors need parent/guardian permission. Do not treat prepared code or adult demonstrations as learner-generated AI output. Connector exercises are optional adult demonstrations or practice by eligible users.

- Keep HTML, CSS, and JavaScript dependency-free. GitHub Pages serves the repository root.
- The homepage is a pool of twelve task-based bilingual modules, with a persistent lesson directory and one selected lesson visible at a time; project demonstrations belong to the instructor’s live presentation and must not be embedded in the website. Do not assume one ability level or lock navigation. Each lesson starts with an everyday use and a concrete sample result, then short actions. Further challenges, quizzes and records are optional disclosures, not prerequisites. Do not split learner and instructor content into different pages or link to instructor.html/next-steps.html from the main lesson. Keep earlier phone/computer workshops in practice.html as optional material.
- Label fictional exercises, prepared outputs, and reconstructed project demos.
- Public previews are fictional reconstructions, never captures or embeds of private pages. Keep investment examples free of accounts, holdings, strategies, performance, and live trading connections.
- Teach a short initial request, a learner-authored change, source checks, and saving the result. Preserve old workshop schedules only within their optional archive. Do not present lesson slices as completion of entire modules.
- Never publish private source data, wardrobe metadata, photos, infrastructure, credentials, or private Notion content.
- Distinguish rule engines, AI generation, retrieval, and automation in project summaries.
- Keep phone layouts, keyboard focus, touch targets, and text feedback usable.
- Use a compact document-style layout with clear chapter navigation. Default headings stay at 28px or smaller, without oversized marketing heroes or large decorative whitespace.
- Use white and gray surfaces, dark text, and restrained blue accents. Avoid the previous sage/cream palette, ornamental cards, gradients, and shadows unless the user explicitly changes direction.
- Use DOM text APIs for visitor input. Preview HTML only in a sandbox without same-origin privileges.
- Validate syntax, links, anchors, totals, quiz answers, schedules, PDFs, and browser interactions before publication.
- Keep README.md as the entry point and HANDOFF.md as delivery and validation status.
- Keep the Chinese and English lessons, dynamic prompts, feedback, examples, and after-class paths equivalent. Language switches stay visible on narrow screens and warn before discarding edited text or code. Keep learner input unchanged.
- After-class progress is optional, shared between languages, and self-reported. Never imply a checked stage automatically verifies a learner's project.
- Everyday analysis is a separate two-lesson course, 60 minutes per lesson. Lesson 1 uses September only; lesson 2 adds October. Keep unknown amounts distinct from zero and known subtotals distinct from complete totals. Public travel reconstructions use fictional data, with no private source links or real locations. Market exercises compare fictional public-style volume data, not account performance.
- instructor.html and next-steps.html are compatibility redirects into the same course. scripts/build_course.py delegates homepage rendering and lesson downloads to scripts/build_curriculum.py using curriculum-content.json; scripts/learning_layout.py renders the current learning interface; course-content.json, seminar-content.json and templates/showcase-*.html are legacy data, not homepage content. Never hand-edit generated homepages. build_companion_pages.py delegates to it. The optional earlier guides and PDFs remain separate extensions and must not be presented as the current course.
- Distinguish actual AI-generated code from prepared fixtures, simulations and fixed templates. Code previews remain sandboxed without same-origin privileges and block external connections. Keep persistence behavior explicit; edited code must invalidate the prior preview. Never render learner text as parent-page HTML. Home means sensor readings and device rules, not household finances.
